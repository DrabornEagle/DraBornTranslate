# DraBornTranslate v0.4.13 — GTA 6 Türkçe paket öncelikli çeviri

## Yenilikler

- **GTA 6 Türkçe paketini indir / güncelle:** GameTranslator v1.8.50 ile uyumlu Türkçe oyun paketi, kullanıcı isteğiyle üçüncü tarafın genel paket sunucusundan indirilir.
- **Paket önceliği:** Eşleşen diyaloglar yerel çeviri modelini beklemez. Pakette bulunmayan metinler ML Kit veya ONNX ile çevrilir.
- **Kontrol:** HTTPS dosyası sunucunun SHA-256 beyanıyla doğrulanır; hatalı güncellemede eski paket korunur. Kurulu dosyadaki gerçek satır sayısı gösterilir.
- **Lens:** Ekranda okunan İngilizce oyun yazıları Android telefon ekranında Türkçe olarak görünür.
- **Tasarım:** GitHub README için yeni renkli başlık, rozetler, kurulum ve açık kaynak bilgileri.
- **Platform:** Android 10+, ARM64, versionCode 22.

## Sınırlar

GameTranslator'ın yaklaşık 475 bin satır iddiası bağımsız olarak doğrulanmamıştır. Üçüncü taraf oyun metinleri APK içinde dağıtılmaz. Altyazısız ses OCR ile çevrilemez. PS Portal'ın fiziksel ekranına doğrudan Lens katmanı eklenemez.

## Kurulum

İmzalı APK'yı eski sürümün üzerine yükle. GTA 6 paketi için **Görünüm ve oyun paketi → Oyun paketi → GTA 6 Türkçe paketini indir / güncelle** seç.
